# 长期记忆与自动总结使用教程

本文介绍新版自动总结、结构化记忆、变量记忆、表格记忆和可选向量召回的使用方式。

## 一、最快开始方式

1. 打开某个联系人的聊天设置。
2. 进入“总结”。
3. 将“记忆整理模式”设置为“智能混合（推荐）”。
4. 开启“自动总结”。
5. 保持默认的“条数或 Token”触发方式即可。

不配置独立总结节点时，系统会自动使用全局聊天节点。没有配置向量节点也不会影响自动总结、事件、变量或表格记忆。

## 二、六种记忆整理模式

- 智能混合：一次生成叙事摘要、角色主观记忆、事件、变量和表格记录，适合绝大多数用户。
- 经典叙事：以一段连续的客观摘要为主，兼容旧版记忆书架。
- 角色主观：重点保存角色第一人称的感受，主观理解与客观事实会分开存放。
- 事件卡：重点保存事件时间、参与人物、结果、决定、未完成事项和关系变化。
- 变量记忆：重点维护称呼、喜好、禁忌、边界、习惯、关系、计划和当前状态。
- 表格记忆：重点生成可查看、编辑的分类记录。

智能混合还会建立带起止时间和证据的关系图谱，例如“用户—喜欢→某物”“角色—承诺→某件事”。关系可以在结构化记忆的“关系”页查看和修改。

## 三、自动触发设置

### 消息条数

未总结消息达到设置数量后执行。默认 500 条。

### Token 阈值

根据聊天文本长度估算 Token；超过阈值后执行。适合消息长短差异较大的聊天。

### 重要标记触发

出现被标记的重要消息时提前整理，防止其在长对话中被遗漏。

### 话题切换触发

系统通过本地关键词重合度判断最近对话是否明显转入新话题。该功能不会额外调用模型；容易频繁换话题的用户可以关闭。

### 空闲后台整理

设置若干分钟后，用户停止继续发送消息时整理当前积压内容。设置为 0 表示关闭。

### 离开聊天时整理

离开当前聊天前处理尚未整理的内容。因为需要等待总结 API 返回，返回上一级页面可能比平时稍慢。

## 四、批次和记忆预算

- 单批消息数：一次发送给总结模型的最大消息数，建议 100–200。大量积压会自动拆成多批，并在每批完成后保存断点。
- 记忆注入预算：每轮聊天允许注入的长期记忆 Token 估算上限。建议 800–1600。
- 分层记忆巩固：阶段摘要达到阈值后自动生成一条更高层长期摘要，原摘要保留为归档证据，不再重复注入。

提高预算可以提供更多历史，但也会增加费用和噪声。系统不会再把整个记忆书架无条件注入每一轮对话。

## 五、独立总结节点

路径：应用的“API 节点配置” → “总结节点”。

1. 开启独立总结节点。
2. 选择服务商或填写自定义兼容地址。
3. 填写 API 密钥。
4. 同步或手动填写聊天补全模型。
5. 使用页面内的自定义测试弹窗检查连接。

总结节点未启用或配置不完整时，会继续使用全局聊天节点。

## 六、向量节点

向量节点完全可选，只用于提高大量长期记忆的语义召回效果。

路径：应用的“API 节点配置” → “向量节点”。

1. 开启独立向量节点。
2. 填写兼容 OpenAI `/v1/embeddings` 格式的 API 地址和密钥。
3. 填写真正的 Embedding 模型名称，不要填写普通聊天模型。
4. 点击“测试”，成功时会显示返回的向量维度。
5. 回到联系人的“总结”页面，点击“向量索引 → 重建”。

未配置向量节点时，系统自动使用关键词、人物、标签、时间、重要度和未完成状态混合召回。

更换 Embedding 模型后应重新构建索引。向量存储在 IndexedDB，不存入 localStorage；联系人正文、结构化记忆和备份仍可正常使用。

## 七、管理结构化记忆

在“总结”页面点击“结构化记忆”，可分别查看：

- 事件：事件摘要、重要度、时间、未完成事项和证据数量。
- 变量：分类、键、当前值、置信度、旧值数量和证据数量。
- 表格：人物、喜好、事件、承诺、礼物、关系、时间线、冲突和地点等分类。
- 关系：人物或实体之间带时间、置信度和证据的关系图谱。

每一项都可以编辑或删除。变量上的“锁定”用于保护人工确认的内容；锁定后，自动整理不会覆盖该变量的值。

删除或修改记忆时，已配置的向量索引会自动同步。也可以随时手动重建。

## 八、事实更新与证据

每个事件、变量和表格行都会保存来源消息 ID。变量发生变化时：

1. 新值成为当前有效值。
2. 旧值进入历史记录。
3. 后续聊天默认只注入当前有效值。
4. 人工锁定的值不会被自动覆盖。

模型输出仍有可能出错，因此建议定期检查关系状态、日期、承诺和敏感边界等重要记忆。

## 九、旧版数据兼容

旧版记忆书架会继续显示。首次使用新版记忆时，旧的总结游标会迁移为覆盖区间；以后手动总结任意区间，不会再导致前面的未总结内容被误跳过。

旧摘要可以直接参与本地召回；配置向量节点后，通过“重建”即可为旧摘要补充向量。

## 十、推荐配置

一般聊天：

- 智能混合模式
- 条数或 Token
- 300–500 条
- 4000–6000 Token
- 单批 150 条
- 记忆注入预算 1200 Token
- 重要标记触发开启
- 话题切换触发按需要开启

长篇角色扮演：

- 智能混合或事件卡模式
- 150–300 条
- 3000–5000 Token
- 记忆注入预算 1200–1800 Token
- 建议配置独立总结节点和向量节点
