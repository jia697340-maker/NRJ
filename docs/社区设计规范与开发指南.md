# 社区（论坛）设计规范与开发指南 (Design System & Guidelines)

> **警告：** 本项目专属“粘人精”，严禁在任何地方（代码、变量名、文件名、注释等）使用周棋洛或其相关英文/拼音命名！所有新增代码必须保持克制、真实社交感，严禁破坏本设计地基。

---

## 一、 核心设计哲学与原则

1. **真实人类社交感（No AI Vibes）**：
   - 社区中所有模拟网友、发帖人、评论者在 UI 层均展示为真实普通网友。
   - 严禁在界面中出现“AI角色”、“机器人”、“智能网友”、“AI推荐给你的人”等破坏沉浸感的文字。
2. **克制与成熟（No Cheap SaaS / AI Demo Aesthetics）**：
   - 严禁滥用大面积紫蓝渐变卡片、夸张的大圆角阴影堆叠、每个模块套一个 Card 的 AI 默认模板风格。
   - 普通动态流保持平铺 + 细轻线（1px border-bottom）设计，信息流紧凑、呼吸感自然。
3. **严格继承现有主题系统**：
   - 所有组件的颜色与背景必须基于项目的 CSS 变量（如 `--sys-bg-primary`, `--sys-bg-secondary`, `--text-primary`, `--text-secondary`, `--border-color`, `--accent-color` 等）。

## 三、 扩展规则（AI 与开发者守则）

1. **新增帖子类型**：
   - 必须在 `src/types/forum.ts` 中扩展 `ForumPostType`，并在 `ForumFeedItem.vue` 中进行统一渲染分支处理，而不是在每个视图内单独写一套帖子卡片。
2. **新增用户相关功能**：
   - 必须从 `ForumProfileView.vue` 进行扩展（如扩展 Tab、增加徽章、添加动态筛选），严禁为特定用户另起一套主页。
3. **状态与逻辑抽离原则**：
   - 当 `<script setup>` 逻辑超过 150 行时，必须提取到 `src/composables/useForumXxx.ts` 中。
4. **图片与媒体存储**：
   - 严禁在 `localStorage` 存储 Base64 格式的大图片！涉及本地持久化必须使用 `localforage` 存入 IndexedDB。
