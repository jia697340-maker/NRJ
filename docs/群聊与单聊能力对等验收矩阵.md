# 群聊与单聊能力对等验收矩阵

完成状态必须同时覆盖：设置入口、数据持久化、提示词、历史编码、输出解析、界面渲染、业务交互和自动化测试。仅有开关或仅能显示，不算完成。

| 能力 | 单聊基准 | 群聊额外要求 | 验收状态 |
| --- | --- | --- | --- |
| 双语对话 | 开关、控制模式、输出语言、翻译语言、显示方式 | 群级设置必须权威覆盖成员单聊设置；关闭后不得偷偷继承 | 通过（自动化） |
| 时间感知 | 用户/角色时区、当前时间、历史时间戳、角色时间戳开关 | 每个成员使用自己的群内时区，用户使用群内用户时区 | 通过（自动化） |
| 气泡叙事 | 开关、叙事协议、独立渲染 | 带发送成员身份，不能破坏群消息协议 | 通过（协议测试） |
| 回复条数 | 开关、最小/最大数量 | 约束群消息总量，不得继续要求单聊 `<msg>` | 通过（含反向断言） |
| 心声 | 自动生成、双方历史开关与数量、存储限制 | 每位成员隔离保存和读取 | 通过（成员隔离） |
| 线下模式 | 模式、预设、模型适配、地点处理 | 多成员现场连续性和成员身份 | 通过（混合/独立） |
| 图片 | 真实图片载荷、视觉压缩、角色真实生图 | 图片发送者和生图角色必须明确 | 通过（真实载荷/成员生图） |
| 语音 | 转写上下文、TTS 播放、语音配置 | 按发送成员选择语音配置 | 通过（成员级） |
| 转账/红包 | 金额备注、钱包、领取拒绝退款过期 | 明确发送成员并保持钱包生命周期 | 通过（钱包测试） |
| 通话 | 语音/视频生命周期和记录 | 群通话参与成员、类型和状态不得降级 | 通过（参与者/记录/上下文隔离） |
| 世界书 | 书籍与分组绑定 | 群共享与成员私有世界书边界明确 | 通过（书籍+分组） |
| 用户人设 | 人设选择、编辑、时区、固定形象 | 群内快照可查看更新，提示词只能使用同一份身份 | 通过（群内快照权威） |
| 成员资料 | 角色全量设置 | 支持群内覆盖且不污染私聊 | 通过（覆盖+明确同步） |
| 美化 | 气泡、头像、昵称、时间、耗时、背景 | 成员专属头像和群头像刷新后仍生效 | 通过（复用单聊美化面板） |
| 衍生 | 总结、消息数、Token 统计 | 群共享记忆与成员主观记忆分别统计 | 通过（真实群载荷） |

## 交付门槛

1. 类型检查、Lint、原有测试、新增群聊回归测试和生产构建全部通过。
2. 设置保存后重新加载，值和行为均保持一致。
3. 群聊关闭某项能力时，不得由成员单聊设置绕过。
4. 群聊输出协议不得与单聊 `<msg>` 协议互相冲突。
5. 最终差异审计不得包含与本任务无关的删除或重构。
